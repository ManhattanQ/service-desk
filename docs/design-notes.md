# Design notes

Заметки по дизайну для будущей реализации (собираются по ходу обсуждения, до старта верстки).

## Элементы ожидания / пустые состояния (loading / empty state)

- Идея: использовать **пиксельного человечка в деловом (рабочем) костюме**, который что-то печатает на компьютере, как визуальный элемент ожидания/загрузки (loading spinner замена) или как иллюстрация для пустых состояний (например, "Очередь заявок пуста", загрузка данных, обработка запроса).
- Стиль — pixel art.
- Использовать в местах, где сейчас был бы обычный спиннер/скелетон: загрузка таблицы заявок, загрузка дашборда, сохранение формы и т.п.
